# Гиря — офлайн-трекер гиревого спорта

Сайт: https://faritmustafin37-glitch.github.io/girya/

Откройте на iPhone в Safari или на Android в Chrome, добавьте на экран «Домой», один раз запустите с интернетом и дождитесь «Офлайн готов». Дальше интернет и VPN не нужны: нейросеть позы и все файлы хранятся в телефоне.

Здесь лежит готовая сборка (`npm run build:static`). Исходники — в проекте «Гиревой трекер» на Mac.
